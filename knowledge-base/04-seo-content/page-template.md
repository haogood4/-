# 计算器页面 SEO 内容模板

> 每个计算器页面的正文结构必须按本模板填充。

## 页面结构

```
[Title]
[Meta Description]
[H1 工具名]

[简介 80–120 字，含主关键词]

[H2 使用方法]
（4 步图文，说明如何输入 + 查看结果）

[H2 公式说明]
（直接引用 03-formulas 中的公式人话版 + 公式图）

[H2 结果解读]
（说明主结果字段含义，给出 2–3 个示例场景）

[H2 注意事项 / 免责声明]
（YMYL 类必填）

[H2 常见问题 FAQ]
（5–8 条，每条 30–80 字）

[关联工具推荐]
（3–5 个同分类工具）

[最后更新时间]
（YYYY-MM-DD）
```

## 字段填写模板

| 字段 | 模板 |
|---|---|
| Title | `{keyword}：{value} | {brand}` |
| Meta Description | `使用 {brand} 的 {keyword}，快速{action}。支持 {feature1}、{feature2}。免费、无需注册。` |
| H1 | `{keyword}` |
| URL | `/{category}/{slug}/` |
| Canonical | `https://example.com/{category}/{slug}/` |

## 内容质量门槛

- 至少 800 字有效正文（不含代码与模板）。
- 至少 1 张原创信息图（计算器截图 / 公式图）。
- 至少 3 条 FAQ。
- 必须有"最后更新时间"。
- YMYL 必须有"作者/审核人"署名。
