# YMYL 内容审核规则

## 范围

涉及以下领域的页面视为 YMYL：

- 金融（贷款、投资、保险、税务）
- 健康（疾病、症状、药物、BMI、孕期）
- 法律
- 重大人生事件（退休、移民）

## 强制要求

1. **E-E-A-T 署名**：显示作者 + 审核人。
2. **来源链接**：每个数据/公式至少 1 个 official 来源。
3. **免责声明**：结果页与 SEO 摘要页都必须显示。
4. **事实核查**：每 6 个月由人类审核人复核。
5. **禁止**：广告诱导、虚假承诺、未证实的对比。

## 程序化广告内容审核

程序化广告内容无法逐条人工预审。采用平台侧控制（敏感类别屏蔽、广告主屏蔽）+ 定期抽查 + 用户投诉处理机制。发现违规广告的投诉渠道：[联系方式待填写]

## 编辑流程

```
草稿（AI）→ SEO 自检 → 内容负责人 → 领域专家 → 上线
```

每一步在 GitHub PR 中以 `approve` 标签记录。

## 风险词清单（禁止在文案中出现）

- "保证"、"100% 准确"、"无风险"、"稳赚"
- "权威推荐"、"排名第一"
- 任何对比类绝对结论（"X 比 Y 更好"）
- 任何医疗/法律诊断口吻
