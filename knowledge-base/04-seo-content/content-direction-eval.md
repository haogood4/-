# 内容方向评估方法论 v1.0.0

## 1. 目的

为「内容投资决策」提供**可重复、可量化、可对照**的评估方法。任何新增内容类型在投入资源前必须用本方法打分；得分低于 3.0 一律标记为 deferred（延后）或 rejected（驳回），不得进入实施阶段。

## 2. 数据来源

| 类型 | 来源 | 用途 |
|---|---|---|
| **本站基础数据** | 6 分类关键词库（`knowledge-base/04-seo-content/keyword-bank/v2/*.md`，6 份） | 长尾词数量、搜索意图分类（信息型/交易型/导航型） |
| **公开搜索量代理** | 百度指数 / 微信指数 / Semrush 公开数据（如可访问） | 用户需求强度 |
| **同类竞品** | timeanddate.com / 各类「房贷计算器」站点 / 美团 / 链家「工具」频道 | 内容形态参考、参与度代理 |
| **本站缺失数据** | ① 真实 GA 数据（部署前无数据）；② 用户调研（项目预算未含调研费用） | **不假设数据**；以「代理估算」标注非历史值 |

**诚实声明**：所有「预期 KPI」为同类站点公开数据 + 合理推断，**非基于本站真实历史**。上线后 90 天内应用真实 GA 数据校正本评估。

## 3. 评分维度（5 维度，0-5 分，加权）

### 3.1 用户需求满足度（权重 25%）

| 分 | 含义 | 判定依据 |
|---|---|---|
| 5 | 强需求、高搜索量、明确信息缺口 | 长尾词 ≥500/月 + 用户调研/竞品证明 |
| 4 | 明确需求 | 长尾词 200-500/月 |
| 3 | 中等需求 | 长尾词 50-200/月 |
| 2 | 弱需求 | 长尾词 <50/月 |
| 1 | 边缘需求 | 偶发长尾词 |
| 0 | 无需求 | 搜索量为零 |

### 3.2 战略契合度（权重 20%）

与「计算器大全」核心价值（提供准确、免费、可信的计算工具解决方案）的距离：

| 分 | 含义 |
|---|---|
| 5 | 完全契合（如金融公式推导，与工具页直接互补） |
| 4 | 强契合（如工具使用指南） |
| 3 | 中性（如工具使用场景的生活化故事） |
| 2 | 弱契合（如泛资讯） |
| 1 | 边缘（如娱乐八卦） |
| 0 | 偏离（如与计算无关内容） |

### 3.3 实施难度（权重 15%，分高 = 易实施）

| 分 | 含义 | 工时/资源参考 |
|---|---|---|
| 5 | 纯静态 Markdown + 现有模板 | ≤1 人月 |
| 4 | 静态 + 少量前端模板 | 1-2 人月 |
| 3 | 静态 + 自建模板 + 多角色协作 | 2-4 人月 |
| 2 | 需引入新依赖（数据库 / 第三方服务） | 4-8 人月 |
| 1 | 需自建后端 | ≥8 人月 |
| 0 | 需复杂业务（支付/账户/合规资质） | ≥3 人季度 |

### 3.4 预期参与度提升（权重 25%）

对核心指标（停留时长 / 跳出率 / 复访率 / 工具点击率）的提升估计：

| 分 | 含义 |
|---|---|
| 5 | 停留 +120s 以上；工具点击率 +30% 以上；复访率 +40% |
| 4 | 停留 +60-120s；点击率 +15-30%；复访率 +25-40% |
| 3 | 停留 +30-60s；点击率 +5-15%；复访率 +10-25% |
| 2 | 停留 +10-30s；点击率 0-5%；复访率 0-10% |
| 1 | 仅带来流量，对参与度影响小 |
| 0 | 无影响或负影响 |

### 3.5 长期可持续性（权重 15%）

内容生产成本（一次性 vs 持续）+ 更新频率 + 可扩展性：

| 分 | 含义 |
|---|---|
| 5 | 一次性生产 + 极少更新 + 模板可扩展 |
| 4 | 一次性 + 季度更新 |
| 3 | 月度更新 1-2 篇 |
| 2 | 周更 2-3 篇 |
| 1 | 日更 1+ 篇 + 持续审核 |
| 0 | 需要实时生产或高频社区运营 |

## 4. 加权公式与分级

```
总分 = 用户需求 × 0.25 + 战略契合 × 0.20 + 实施难度 × 0.15 + 参与度 × 0.25 + 可持续 × 0.15
```

| 总分区间 | 分级 | 决策 |
|---|---|---|
| ≥4.0 | **P0** | 必做（投入资源实施） |
| 3.0-3.9 | **P1** | 应做（资源允许时做） |
| 2.0-2.9 | **P2** | 可做（低优先级） |
| <2.0 | **rejected** | 驳回（理由记录） |

## 5. 决策树

```
任意方向 → 5 维度独立打分 → 加权求和
  ├── ≥4.0 → P0 → 立项（单独 change-id）→ 季度回顾
  ├── 3.0-3.9 → P1 → 资源允许时做 → 月度回顾
  ├── 2.0-2.9 → P2 → 暂存，6 个月后复评
  └── <2.0 → rejected → 文档化理由，避免反复评估
```

## 6. 与既有体系一致性约束

- 复用 [`seo-standards.md`](seo-standards.md) 的元数据规范（每页 unique title/meta/JSON-LD）
- 复用 [`ymyl-rules.md`](ymyl-rules.md) 的金融/健康内容免责要求
- 复用 [`schema-org.md`](schema-org.md) 的 Article / FAQPage 结构化数据
- 不与 [`04-seo-content/README.md`](README.md) 的关键词分层冲突
- 合规遵循 PIPL + 广告法 + 医疗广告法 + 互联网新闻信息服务管理规定（资讯类内容）

## 7. 复评周期

- P0 方向：每季度复评（基于真实数据校正评分）
- P1 方向：每半年复评
- P2 / rejected 方向：每年复评或遇重大市场变化时复评
