## 流程

1. 发现人通过 GitHub Issue 创建，标签 `bug` / `content` / `infra` / `risk`。
2. 由 PM 在每周一站会分类到：bug / 需求 / 风险。
3. 重要问题（影响上线或合规）升级到 `risk-register.md`。
