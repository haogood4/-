# 风险登记册 · Risk Register

## 评级规则

- **概率**：1 极低 / 2 低 / 3 中 / 4 高 / 5 极高
- **影响**：1 极小 / 2 小 / 3 中 / 4 大 / 5 灾难
- **风险值 = 概率 × 影响**
- **等级**：1–4 绿 / 5–9 黄 / 10–15 橙 / 16–25 红
