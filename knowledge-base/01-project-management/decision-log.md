# 决策日志 · Decision Log

> 永久追加的"为什么这么做"记录。
> 任何重大决策（技术选型、范围变更、公式变更、放弃功能）必须在此登记。

## 决策记录模板

| 字段 | 含义 |
|---|---|
| 日期 | YYYY-MM-DD |
| 决策编号 | DEC-YYYYMMDD-NNN |
| 决策事项 | 一句话 |
| 候选方案 | 列 2–4 个 |
| 最终决定 | 选哪个 |
| 决策原因 | 优劣势对比 |
| 影响范围 | 受影响的模块/团队 |
| 决策人 | 谁拍板 |
| 反悔成本 | 高/中/低 |

---

> 新增决策请复制本节"## DEC-..."格式追加到文件末尾，不要修改历史条目。
