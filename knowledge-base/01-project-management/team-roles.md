# 角色与职责 · RACI

## 角色清单

| 缩写 | 角色 | 主要职责 |
|---|---|---|
| PM | 项目经理 | 计划、协调、风险、跨团队沟通 |
| PO | 产品经理 | 需求、上线验收 |
| UX | UI/UX 设计师 | 设计稿、组件库、可访问性 |
| FE | 前端工程师 | 页面、交互、性能 |
| BE | 后端工程师 | API、数据、公式引擎、部署 |
| SEO | SEO / 内容运营 | 关键词、内容、外链 |
| QA | 测试 | 自动化、兼容、QA 报告 |

## 决策权

| 事项 | 最终决策人 | 必须咨询 |
|---|---|---|
| MVP 范围调整 | PO | PM, BE, FE |
| 公式变更 | BE + PO | 法务（如涉税/医疗） |
| 技术选型 | 技术负责人（BE Lead） | PM, FE |
| 上线发布 | PM | PO, QA |
| 广告位调整 | PM | SEO |
| 关键词策略 | SEO | PO |
