# 空状态与错误信息规范

## 1. 空状态

- 文案："填写上方字段后显示结果"（不含方位词，适配移动优先单列布局）。
- 图标：简洁线条图标，灰色。

## 2. 错误信息

| 错误类型 | 措辞规则 | 示例 |
|---|---|---|
| 必填缺失 | "请填写{字段名}" | "请填写贷款金额" |
| 数值范围 | "请输入 {min}–{max} 之间的值" | "请输入 1–30 之间的年限" |
| 类型错误 | "请输入有效数字" | "利率请输入数字" |
| 单位错误 | 自动转换，不显示错误 | — |
| 系统异常 | "服务异常，请稍后重试" + 错误 ID | "服务异常，请稍后重试（#A1B2）" |

## 3. 通用文案原则

- 不使用感叹号；
- 不使用恐吓性词语；
- 给出可执行的修正建议；
- 财务类错误必须避免误导，使用"请确认"而非"错误"。
