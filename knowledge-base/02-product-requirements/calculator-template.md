## 6. 结果解释（文案）

> AI 写作时使用，但必须以知识库中已通过的版本为准。

```
月供 ¥X 表示您每月需要偿还的金额。
其中 ¥Y 为利息，¥Z 为本金。
本结果仅供参考，实际以银行审批为准。
```

## 7. 异常与边界

| 场景 | 行为 |
|---|---|
| 贷款金额 ≤ 0 | 提示"请输入大于 0 的贷款金额"，按钮禁用 |
| 年限 < 1 或 > 30 | 提示范围 |
| 利率 > 30 | 警告"利率异常，请确认"，不阻断 |
| 提前还款金额 > 贷款金额 | 提示"提前还款金额不能超过剩余本金" |

## 8. 免责声明（强制）

```
本计算结果仅供参考，不构成任何投资或贷款建议。
实际月供、利率、还款方式以贷款机构最终审批为准。
```
