# 异常指标处理流程

## 标准格式：问题 → 根因 → 方案 → 预期结果

### 示例

| 项 | 内容 |
|---|---|
| 问题 | 完成率从 70% 跌到 45% |
| 根因 | 表单错误提示不显眼；移动端默认值被误清空 |
| 方案 | 重做错误样式；保留输入值；增加"恢复默认"按钮 |
| 预期 | 完成率回到 ≥ 60% |

## 检查表

### 流量异常

- [ ] GSC 是否有新异常
- [ ] CDN 是否正常
- [ ] robots.txt 是否变更
- [ ] 是否有大流量页面被意外下线

### 计算异常

- [ ] Sentry 是否有 N+ 异常
- [ ] 公式库版本是否一致
- [ ] 边界值处理是否回归

### 收入异常

- [ ] AdSense 政策提醒
- [ ] CTR 异常 / 广告位变更
- [ ] 是否有违规内容

## 升级路径

```
数据监控发现 → 自动 Slack 告警 → PM 5 分钟内确认 → 决策：修复 / 降级 / 关停
```
