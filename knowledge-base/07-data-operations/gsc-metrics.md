# Search Console 指标说明

## 关键指标

| 指标 | 含义 | 关注阈值 |
|---|---|---|
| Clicks | 搜索结果点击数 | 月环比 ≥ +15% |
| Impressions | 展现次数 | 月环比 ≥ +20% |
| CTR | 点击率 | ≥ 4% |
| Position | 平均排名 | 主关键词 ≤ 10 |

## 关注页面

- 主关键词 Top 10 页面
- 展现 > 1000 但 CTR < 2% 的页面 → 优化 Title / Description
- Position 11–20 的页面 → 内链 + 内容增强

## 关注查询

- 排名 4–10 接近首页的查询 → 内容升级
- 长尾带来流量的查询 → 扩展为单独页面

## 异常处置

| 现象 | 行动 |
|---|---|
| Impressions 突降 | 检查 robots / CDN / Sitemap |
| CTR 突降 | 调整 Meta；增加 FAQ |
| Position 集体下滑 | 检查内容质量 / 是否触发 Helpful Content |
