## 4. 上线后运维

### 4.1 监控指标（5 项必看）

| 指标 | 目标 | 采集来源 | 告警阈值 |
| :-- | :-- | :-- | :-- |
| 可用性 | ≥ 99.9%（滚动 30 天） | 合成监控 + 真实用户监控 | < 99.5% 持续 10 min |
| JS 异常率 | ≤ 0.1%（滚动 24h） | Sentry | > 0.3% 持续 10 min |
| 计算失败率 | ≤ 0.05%（按计算器维度） | 埋点 + 单元测试失效率 | 单计算器 > 0.2% 持续 30 min |
| 性能 P75（LCP / INP / CLS） | LCP ≤ 2.5s / INP ≤ 200ms / CLS ≤ 0.1 | Web Vitals（RUM） | 任一项 P75 越限持续 1h |
| 广告政策通知 | 0 待处理 | 广告后台 + 站内信 | 任一平台下发通知 24h 内未确认 |

### 4.2 故障处理 4 步流程

1. **响应**：on-call 收到告警后 5 分钟内确认；30 分钟内判定严重级别并通知干系人。
2. **定位**：按"监控指标 → Sentry → 日志 → 复现"顺序逐级下钻；必要时启动 War Room。
3. **修复**：遵循发布与回滚 SOP；高严重度故障优先回滚到上一个稳定版本；修复后补自动化用例。
4. **复盘**：48 小时内出 RCA，写明时间线、根因、影响面、修复与预防措施，纳入风险登记册。

### 4.3 日常维护计划

- **依赖升级**：每月一次，遵循语义化版本约束；升级前必跑 Playwright 主流程与 Lighthouse 报告。
- **Lighthouse CI**：每次 PR 自动跑一次；分数低于阈值（性能/可访问性/SEO < 95）必须修复或豁免签字。
- **定期 YMYL 复核**：每季度一次，由 SEO/内容 + 法务 + 产品联合复核免责声明、来源、E-E-A-T 证据链。

- **外部专业审核（YMYL 复核）**：BLOCKED。原因：外部专业审核预算未定，季度复核的资源与外部审稿专家尚未到位；待预算审批后启动并归档复核报告。
