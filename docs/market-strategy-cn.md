# 大陆市场策略 v2

> 来源：`.trae/specs/strategy-50-calculators/spec.md`（已批准）。
> 适用范围：所有 50 工具矩阵 + 既有 11 工具的合规口径回写。

---

## 1. 市场定位

- **目标用户**：中国大陆中文用户（已批准事实）
- **合规口径**：PIPL（个人信息保护法）+ 银保监会（金融工具）+ 国税总局（税务工具）+ 国家卫健委（健康工具）
- **金融工具免责声明**：所有金融/税务/健康类工具以"草案/参考"标注上线，不要求外部专业审核；用户在结果区可见显著提示

### 盈亏平衡公式（大陆口径）

```
月 PV 盈亏平衡 = (月度运营预算 ÷ 页面 RPM) × 1000
```

**行业参考区间**（中文工具站，大陆流量为主）：

- 展示广告 RPM：¥3-15 / 千次
- CPC 广告：¥0.10-1.50 / 点击
- 搜索广告 RPM：¥10-50 / 千次
- 信息流广告 RPM：¥5-20 / 千次

**示例**：

| 月度预算 | RPM | 所需月 PV |
|---|---|---|
| ¥500 | ¥5 | 100,000 |
| ¥1000 | ¥8 | 125,000 |
| ¥3000 | ¥10 | 300,000 |
| ¥5000 | ¥12 | 416,667 |

> 区间来自公开经验值，非承诺；上线后按真实数据回填。

## 5. 竞争分析

| 竞品类型 | 代表 | 我们的差异点 |
|---|---|---|
| 工具聚合站 | toolin.cn / wannengcha calc | 工具深度 + 内容质量 |
| 单一金融工具站 | 融 360 / 卡牛 | 50 工具矩阵 + SEO 长尾 |
| 大厂工具 | 百度计算器 | 不投广告位 + 不绑定生态 |
| 程序员工具站 | 在线工具 / bejson | 大陆用户 + 金融专业 |

**差异化优势**：

1. 50 工具矩阵覆盖度高于单一金融工具站
2. 工具深度高于工具聚合站
3. SEO 关键词覆盖广于大厂工具
4. 隐私合规优于同类聚合站（最小化数据采集）

## 6. 风险矩阵（高层）

| 风险 | 概率 | 影响 | 缓解 | Owner |
|---|---|---|---|---|
| 个税公式过时（LPR/专项附加扣除变化） | 高 | 高 | 每季度 review + 文案"参考国税务总局公告 XXXX" | PM |
| 金融工具被举报违规 | 中 | 高 | 显著"参考"标注 + 拒绝给具体投资建议 | 法务 |
| 百度算法降权 | 中 | 中 | 内容质量 + E-A-T 信号 + 定期更新 | SEO |
| 广告 CPM 持续下行 | 高 | 中 | 多元化广告平台 + 探索订阅制 | 运营 |
| 实时行情接入成本 | 中 | 中 | 暂用用户输入费率；P2 接入新浪/腾讯免费 API | 前端 |
| ICP 备案被退回 | 中 | 高 | 提前准备主体资料 + 内容合规自检 | PM |
