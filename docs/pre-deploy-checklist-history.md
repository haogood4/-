# 部署历史记录 (Pre-Deploy Checklist History)

> **用途**：跟踪每次部署的执行情况与回滚事件，作为事故复盘与合规审计依据。
> **维护人**：PM（部署完成后 1 个工作日内填写）
> **保留策略**：≥ 1 年；合规要求 ≥ 3 年（按 PIPL 与公司法务要求）

## 表格说明

每行记录一次部署；同一版本多次部署（如 staging → production）分多行记录。
`结果` 字段取自 [pre-deploy-checklist.md §13 决策规则](pre-deploy-checklist.md#13-部署决策规则) 的 GO / HOLD / BLOCKED。
