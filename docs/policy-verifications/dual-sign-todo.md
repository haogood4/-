# 人工复核双签待办清单

> **用途**：统一登记政策资讯首轮 AI 辅助核查产生的全部待复核/待双签事项（首批 7 项：6 篇文章修订复核 + 1 项批次报告签署），提供可排序、可筛选、可追溯的单一追踪入口。数据源为 [`2026-09/`](./2026-09/) 下 6 份核对档案与批次报告；上线闸门为[政策资讯原文核对 SOP](../policy-verification-checklist.md) 使用规则第 3 条（双签生效）及预部署清单 §12 P0 项。复核人按各项「复核要点」逐项核对，结论同步更新档案签字栏与本清单状态列。

**CSV 镜像声明**：本表与 [`dual-sign-todo.csv`](./dual-sign-todo.csv) 为同一数据（CSV 是机器可读镜像）。任何状态/签署/新增事项变更，须在**同一提交内同步两处**；若两处不一致，以本 md 主表为准并立即修正 CSV。

## 字段定义

| 字段         | 约束                                                                         |
| ------------ | ---------------------------------------------------------------------------- |
| ID           | `DS-YYYYMM-序号`，全局唯一、不可复用                                         |
| 优先级       | P0（阻塞上线/存在性风险）/ P1（时效强）/ P2（常规）                          |
| 提交时间     | 进入待办的日期（首批统一 2026-09-19）                                        |
| 当前状态     | 待首签 → 首签通过待二签 → 通过 / 退回重核 / 待二次核对（重写稿），单一状态值 |
| 第一签责任人 | 政策研究员（指定姓名或角色占位）                                             |
| 第二签责任人 | 主编；金融/健康/法律类追加法务                                               |
| 复核截止日期 | P0=提交后 3 个工作日；P1=5 个工作日；P2=10 个工作日                          |
| 关联档案     | 指向对应 `<slug>-verification.md` 链接                                       |

## 状态枚举与逾期规则

- **允许值（禁止自由文本）**：`待二次核对` / `待首签` / `首签通过待二签` / `通过` / `退回重核`
- **逾期规则**：当前日期 > 复核截止日期且状态未达「通过」→ 该项状态后追加 🕐（如 `待首签 🕐`）；逾期未签的文章不得上线，批次风险等级不得降为 🟢。
- 截至 2026-09-19，首批 7 项均未逾期。

## 排序/筛选使用说明

- **Markdown 版**：主表默认按优先级排序（P0→P1→P2，同级按截止日期、再按 ID）；速查用视图 A「按状态速查」与视图 B「按截止日期速查」。
- **CSV 版**：需任意组合排序/筛选时，用表格软件打开 [`dual-sign-todo.csv`](./dual-sign-todo.csv)（UTF-8 带表头，列名固定：`id,item,file,priority,submitted,status,sign1,sign2,due,archive`）。
- **可追溯**：已完成事项不删除，状态改「通过」并在档案签字栏记录签署日期；新增事项只追加新 ID，并同步登记下方「变更记录」。
