## 3. 签核流程

1. **首签**：政策研究员按上表逐项抽验 → 在各档案「附：签字栏」记录姓名/日期 → 登记册状态改「首签通过待二签」
2. **二签**：主编复核表述合规；法务按分类必签（劳动用工/社保生育/金融房产/金融保险/金融收费/金融信贷/税务）→ 状态改「通过」
3. 任何退回意见登记至变更记录，档案版本号 +0.1.0 并注明修订原因
