# 内容方向评估与战略选择 Spec

## Why

当前站点已具备 52 个工具页 + 6 类导航 + SEO 元数据 + 设计系统 + 性能/可访问性基线，但**所有页面均为「工具页」单一内容形态**——纯表单+计算结果，缺失留住用户的「信息内容」。这意味着每次访问都是「来了就走」型即时需求流量，停留时长短、跳出率高、复访率低，SEO 也因缺少长尾内容入口而难以持续获取信息检索流量。

本 spec 输出 5 个差异化的内容方向候选，每个含用户需求、技术路径、合规风险、短期/长期 KPI 与分阶段实施计划，由 PM 选择 1-2 个落地。本 spec **仅做评估与决策框架**，**不写任何代码**——实施产生在后续 per-direction change-id。

## What Changes

- **BREAKING（流程）**：新增 `docs/content-direction-strategy.md`（决策文档，作为内容投资唯一参考），任何新增内容类型必须先在此登记 P0/P1/P2 与 ROI 估算
- 新增 `knowledge-base/04-seo-content/content-direction-eval.md`（评估方法论 + 评分矩阵 + 数据来源说明）
- 更新 `knowledge-base/04-seo-content/content-calendar.md`（仅追加评估导出的 6 个月内容排期初稿，不重写）
- **不实施任何内容页**：本 spec 止于评估与决策

## Impact

- Affected specs：所有依赖「站内丰富内容」的目标（提升停留时长、SEO 长尾、信息检索流量）将以此 spec 结论为前置依赖
- Affected code：
  - `docs/content-direction-strategy.md`（新增）
  - `knowledge-base/04-seo-content/content-direction-eval.md`（新增）
  - `knowledge-base/04-seo-content/content-calendar.md`（追加段）
- 不受影响：业务代码、SEO 工具页、计算逻辑、部署清单

## ADDED Requirements

### Requirement: 评估方法论
评估 SHALL 基于 5 个量化维度，每个方向按 0-5 分评分并加权：
1. **用户需求满足度（25%）**：基于现有 6 分类关键词库（finance/health/renovation/investment/efficiency/daily）的长尾词数量与搜索意图（信息型 / 交易型）占比；用户调研缺失时使用「5118/百度指数/Semrush 关键词搜索量」作为代理指标
2. **战略契合度（20%）**：与「计算器大全」核心价值（提供准确、免费的工具型解决方案）的距离；偏离过远（如纯娱乐短视频）评分低
3. **实施难度（15%）**：人力（PM/编辑/前端/法务）、技术（CMS vs 静态 Markdown vs 外链）、时间（上线到产生流量）；分低/中/高三档折算为分数
4. **预期参与度提升（25%）**：对停留时长（+目标 ≥30s）、互动率（评论/分享/收藏）、转化率（站内点击工具）的影响估算
5. **长期可持续性（15%）**：内容生产成本（一次性 vs 持续）、更新频率需求、可扩展性（同一模板覆盖多少长尾）

#### Scenario: 加权评分决策
- **WHEN** 任意方向总分 ≥4.0
- **THEN** 推荐为 P0（必做）
- **WHEN** 总分 3.0-3.9
- **THEN** 推荐为 P1（应做）
- **WHEN** 总分 <3.0
- **THEN** 标记 deferred（延后）或 rejected（驳回），需在文档中给理由

### Requirement: 5 个候选方向
评估 SHALL 覆盖以下 5 个方向（不可新增/删减以保持评估可比性）：

#### 方向 A：知识库 / Wiki（金融、健康、装修三大类的「概念解释 + 公式推导」长文）
- 形态：每类 5-10 篇长文（1500-3000 字），结构化（导读、公式、举例、FAQ、引用源）
- 落地：Astro Content Collections（Markdown + MDX），复用现有设计系统类名
- 资源：1 编辑 + 0.5 前端 + 0.2 法务审核
- 合规：金融/健康类须引官方源（PIPL + 广告法 + 医疗广告法）
- 预期：长尾 SEO 流量增长、停留时长 +60s、工具页点击率 +15%

#### 方向 B：场景化「决策指南」/ Hub 页（用户场景「首次买房」「装修预算 10 万」「30 岁养老金规划」等的工具组合 + 流程）
- 形态：每场景 1 个 Hub 页，串联 3-7 个工具 + 步骤说明 + 视频/图解
- 落地：复用现有工具页 + 新建 Astro 页面模板（不需 CMS）
- 资源：0.5 PM + 0.5 编辑 + 0.3 前端
- 合规：低（内容已存在于工具页免责范围内）
- 预期：单次访问工具使用次数 ×3、跳出率 −20%

#### 方向 C：UGC 问答 / 评论（用户提问与回答）
- 形态：每个工具页下挂「问答区」
- 落地：需后端（数据库 + 审核），或接入第三方（Giscus / Disqus）
- 资源：1 后端 + 0.5 审核 + 1 法务 + DevOps
- 合规：**高风险**——PIPL 用户数据、广告法标识、医疗建议审核
- 预期：停留时长 +90s、复访率 +25%，但风险与成本极高（**MVP 阶段不推荐**）

#### 方向 D：内容营销 / 博客（行业资讯 + 教程 + 政策解读）
- 形态：每周 2-3 篇资讯文章，紧扣搜索热点（如 LPR 调整、个税新政、医保改革）
- 落地：Astro Content Collections
- 资源：1 编辑（专职）+ 0.3 审核
- 合规：中（需声明「仅供参考，非时事新闻」避免新闻资质要求）
- 预期：新闻型搜索流量增长、社交分享 +40%、权威性建设

#### 方向 E：API / 嵌入式小部件（提供工具 JS SDK 让第三方网站嵌入）
- 形态：输出 `<script src="embed.js" data-tool="mortgage">` 可嵌入片段
- 落地：静态 JS + 服务端拉取计算结果
- 资源：1 前端 + 0.3 DevOps
- 合规：中（CC BY-NC 协议 + 来源链接强制）
- 预期：外链增长、品牌曝光 +200%，但需考虑流量回流转化

#### Scenario: 5 方向评分与决策
- **WHEN** 完成所有 5 方向加权评分
- **THEN** 输出 `决策表`（方向 / 总分 / P0-P2 / 理由 / 关联 spec 链接）

### Requirement: 数据来源与诚实声明
评估 SHALL 在文档头部明示数据来源与限制：
- **基础数据**：本站现有 6 分类关键词库（v2，6 份 Markdown）+ 6 个抽样工具的百度指数/搜索量（公开来源，不含真实时点数据）
- **代理指标**：竞品（如 timeanddate.com / 房贷计算器类站点）的公开目录与流量估算（similarweb / semrush）
- **缺失数据**：① 本站真实 GA 数据（部署前无数据）；② 用户调研（项目预算未包含调研费用）
- **诚实声明**：所有「预期 KPI」为同类站点公开数据 + 合理推断，非基于本站真实历史；上线后 90 天内应用真实数据校正

### Requirement: 实施阶段与里程碑
文档 SHALL 给出每个 P0/P1 方向的三阶段实施：
- **阶段 1（M1-M2，MVP）**：最小可行内容（≤5 篇） + A/B 测试流量入口
- **阶段 2（M3-M6，规模化）**：扩展至 30-50 篇 + Hub 页串联 + 内部链接网络
- **阶段 3（M7-M12，自动化）**：模板化生产 + 自动化 SEO 检测 + 外链合作

每阶段含：负责人（PM/编辑/前端/法务）、预计工时、依赖关系、上线标准、KPI 监测点。

### Requirement: 合规风险分级
每个方向 SHALL 在文档中标注合规风险等级（低/中/高）与具体应对：
- 低：内容已存在于工具页免责范围内
- 中：需法务审核 + 来源标注 + 时效性声明
- 高：需资质（医疗/新闻）+ 数据合规 + 用户协议补充
