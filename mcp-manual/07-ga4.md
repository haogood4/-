# GA4 MCP 使用手册

## 能力

- 报告查询：`runReport`、`getMetadata`。

## 何时使用

| 场景 | 工具 |
|---|---|
| 周报流量 | `runReport` |
| 渠道对比 | `runReport` |
| 事件字典校验 | `getMetadata` |

## 标准查询

### 自然 vs 直接流量

```json
{
  "tool": "ga4.runReport",
  "args": {
    "property": "properties/123456789",
    "dateRanges": [{"startDate": "last_7_days", "endDate": "today"}],
    "dimensions": [{"name": "sessionDefaultChannelGroup"}],
    "metrics": [{"name": "sessions"}, {"name": "engagedSessions"}, {"name": "engagementRate"}]
  }
}
```

### Top 计算器完成数

```json
{
  "tool": "ga4.runReport",
  "args": {
    "property": "properties/123456789",
    "dateRanges": [{"startDate": "last_30_days", "endDate": "today"}],
    "dimensions": [{"name": "customEvent:calculator_id"}],
    "metrics": [{"name": "eventCount"}],
    "dimensionFilter": { "fieldName": "eventName", "stringFilter": { "value": "calc_complete", "matchType": "EXACT" } }
  }
}
```

## 安全规则

- 只读；AI 永远无法写入 GA4。
- 不在报告中出现任何用户标识。
- 报告只发给 PM、SEO、PO。
